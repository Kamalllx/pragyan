# Another secret: 2.5D

You don't necessarily need Blender.

A huge amount of "3D-looking" motion graphics can actually be:

```text
                  CAMERA
                    ↓
       ┌────────────────────────┐
       │                        │
       │       background       │
       │          z=-5          │
       │                        │
       │      ┌─────────┐       │
       │      │  card   │       │
       │      │  z=0    │       │
       │      └─────────┘       │
       │                        │
       │       particles        │
       │          z=2           │
       │                        │
       └────────────────────────┘
```

Move the camera:

```text
camera.x
camera.y
camera.z
camera.rotation
```

and suddenly:

**🔥 cinematic 3D**

This is often called **2.5D**.

It's extremely useful for your project because your architecture diagrams, UI, agent graphs, etc. can become cinematic objects.
